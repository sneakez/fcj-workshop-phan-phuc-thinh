These are the main points I recorded after participating in **First Cloud AI Journey**.

### Overall evaluation

#### Learning environment

I liked being able to choose a project and track my own progress. I had to read documentation, try the work and check the result instead of only following predefined steps.

#### Support from administrators

When an error occurred, I usually checked the logs and tried a fix first. If it still did not work, I shared what I had checked and asked administrators and community members for help.

#### Relevance to my academic major

The program included many topics related to Software Engineering. While building NexusOMS, I worked on code as well as Docker, IAM, ECS, S3, CloudFront, SQS and AWS troubleshooting.

#### Learning opportunities

I attended the first two program events. The Buildathon Kickoff made me think more carefully about the practical problem behind a project. AWS Cloud Day and AI Day gave me a broader view of data, security, cost and how companies use cloud and AI.

### What I valued most

- Learned more about deploying an application to AWS instead of completing only separate labs.
- Better use of logs and resource status during troubleshooting.
- A clearer understanding of sensitive information, IAM permissions and cloud cost.
- Bilingual Workshop documentation that I can review later.

### Challenges identified

- Some labs and screenshots no longer matched the current AWS interface.
- Problems often involved several services and were difficult to isolate.
- Some parts of the project were too large, so work accumulated near the end.
- AWS resources can continue to incur charges if cleanup is overlooked.

### Suggestions for improvement

- Review and repair labs that contain broken links or errors during practice.
- Add a follow-up exercise after each lab so learners can repeat the work independently and check their understanding.
- Provide a checklist for sensitive information, budgets and resource cleanup at the beginning.
- Organize additional training sessions where learners can receive guidance and discuss questions directly.

### Next steps

I plan to continue studying .NET, PostgreSQL, automated testing and AWS security. I also want to rebuild a smaller version of NexusOMS with clearer tests and keep notes about the errors I encounter.

### Conclusion

The program helped me move from following instructions to checking results and finding the cause of failures. This was the most important experience I gained during the internship.
