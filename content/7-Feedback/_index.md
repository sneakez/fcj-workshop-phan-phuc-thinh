### My experience

What I liked about First Cloud AI Journey was the opportunity to choose a project and take responsibility for its progress. While building NexusOMS, I worked not only on code but also on Docker, IAM, ECS, S3, CloudFront, SQS and AWS troubleshooting.

The most difficult part was dealing with issues that appeared after deployment even though the application worked locally. I had to check the Docker image, environment variables, IAM permissions, health checks and logs. This took time, but it helped me understand the relationship between the application and its infrastructure.

I attended the first two program events. The Buildathon Kickoff made me think more carefully about the practical problem behind a project. AWS Cloud Day and AI Day gave me a broader view of data, security, cost and how companies use cloud and AI.

### What I gained

* Experience deploying an application to AWS instead of completing only separate labs.
* Better use of logs and resource status during troubleshooting.
* A clearer understanding of secrets, IAM permissions and cloud cost.
* Bilingual workshop documentation that I can use to repeat the project later.

### Difficulties

* Some labs and screenshots no longer matched the current AWS interface.
* Problems often involved several services and were difficult to isolate.
* Some parts of the project were too large, so work accumulated near the end.
* AWS resources can continue to incur charges if cleanup is overlooked.

### Suggestions for the program

* Record the update date, Region and repository version for each lab.
* Add a verification step after each section so learners can check their result.
* Provide a checklist for secrets, budgets and cleanup at the beginning.
* Hold short weekly reviews so learners receive feedback earlier.

### Next steps

I plan to continue studying .NET, PostgreSQL, automated testing and AWS security. I also want to rebuild a smaller version of NexusOMS with clearer tests and continue documenting the issues I encounter.

### Conclusion

The program helped me move from following instructions to checking results and finding the cause of failures. This was the most important experience I gained during the internship.
